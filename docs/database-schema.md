# Database

PostgreSQL migration: ScholarshipExam.Api/Migrations/*InitialPlatform*.cs. SQLite development creates the equivalent model using EnsureCreated and does not apply PostgreSQL migrations. Do not point development mode at an existing production database.

| Tables | Relationships / constraints |
|---|---|
| AspNetUsers/Roles and Identity tables | Identity-managed hashes, unique normalized user name, roles; alias/consent/disabled state |
| ParentChildren | Parent and child FKs; unique parent-child pair |
| Exams | unique ExternalKey; status, teacher review, content hash, timestamps |
| Questions | exam FK; unique exam/display order; text/topic/explanation/marks |
| Options | question FK; unique question/key; server-only correct flag |
| Payments | payer/student FKs; unique payer/idempotency key; unique nullable reference; decimal amount |
| Subscriptions | student/payment FKs; unique payment ID |
| Entitlements | subscription/exam FKs; unique subscription/exam |
| Attempts | student/exam/subscription/entitlement FKs; unique entitlement; UTC deadline/status/score |
| Answers | attempt/question/option FKs; unique attempt/question; API checks option belongs to question and question to exam |
| Rewards | unique stable code; enabled flag/threshold |
| StudentRewards | user/attempt/subscription FKs; unique AwardKey; Champion key scoped to subscription |
| Audit | actor/action/target/note and UTC timestamp |
| Settings | one row: payment instructions, support email, payment acceptance toggle |

All domain UUID primary keys are generated by application constructors and mapped ValueGeneratedNever so EF never mistakes a new child record for an existing one. DateTime values are UTC on read/write. Decimal precision is set for prices/scores. SQLite serializes decimal values internally; it is only used for local development and tests.

State transitions: Payment AwaitingReference -> Pending -> Approved or Rejected. Direct API reference submission may create Pending in one request. Subscription Active <-> Suspended. Exam Draft -> Published; changes to unpaid content return to Draft; archive only before purchase. Attempt Active -> Submitted or Expired, never reopened.

Migration SQL is included under docs/schema.sql. Review it and test on a fresh PostgreSQL database before deployment. No production migration or restore was executed in this workspace.
